About NutriBot AI

An Agentic AI application built following responsible AI principles.

What is NutriBot AI?

NutriBot AI is a web-based Agentic AI application that leverages IBM's Granite large language model to deliver personalized nutrition guidance. It collects user data, reasons about individual health needs, and autonomously generates a tailored nutrition plan — all while operating within strict ethical guardrails.

Powered by IBM Granite

IBM Granite (granite-13b-instruct-v2) is a family of enterprise-grade AI models designed for safety, transparency, and accuracy. Available via IBM watsonx.ai, Granite models are built with IBM's AI Ethics principles: fairness, robustness, explainability, transparency, and privacy.

Ethics & Guardrails

  • ✅ Harmful content detection & blocking
  • ✅ Medical disclaimer on every plan
  • ✅ No dangerous or extreme diet advice
  • ✅ Respectful, non-judgmental language (HAM framework)
  • ✅ Transparent AI model attribution
  • ✅ Privacy-first: no data storage beyond session

Agentic AI SDLC Phases

  1. Problem Scoping: Personalized nutrition for diverse users
  2. Data & Context: User profile collection via structured form
  3. Agent Design: Planning agent with Granite LLM core
  4. Guardrail Integration: Harmful keyword filter + ethics layer
  5. Tool Use: Plan generation + Q&A + .md export
  6. Evaluation: Output review + disclaimer enforcement
  7. Deployment: Flask API + HTML/CSS/JS web app
